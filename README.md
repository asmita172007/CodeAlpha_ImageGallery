# CodeAlpha Frontend Development Internship - Task 3: Image Gallery

This repository contains a responsive and interactive **Image Gallery** built as part of the CodeAlpha Frontend Development Internship (Task 3).

## Features
- Responsive grid layout adapting to different screen sizes.
- Clean hover effects and styling for enhanced user experience.
- Organized folder structure for assets and source code.

## Tech Stack Used:
- HTML5 (Structure & Semantic Layout)
- CSS3 (Flexbox, Grid & Styling)
